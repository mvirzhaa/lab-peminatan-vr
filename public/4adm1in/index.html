    ➕ Jadwal baru

    Di luar jadwal, Kelas 1, Kelas 2, dan Ruang Rapat terbuka untuk siapa saja. Selama jadwal berlangsung, ruangan hanya bisa dimasuki dengan Token Peserta; dosen/pimpinan masuk dengan Kode Pengajar untuk memegang kontrol kelas. Kedua kode dibuat otomatis setelah jadwal disimpan.

    Cara pakai singkat

    1. Buat jadwal, lalu berikan Kode Pengajar dan Token Peserta kepada dosen/pimpinan rapat.
    2. Dosen membagikan Token Peserta ke mahasiswa/peserta (offline/grup kelas).
    3. Saat jadwal berjalan, pintu ruangan terkunci: pemain memasukkan token di depan pintu.
    4. Presensi tercatat otomatis; unduh Excel dan notulen di daftar sesi di bawah.
